# OpenPencil smoke-test brief

Create a polished 16:9 tvOS source dashboard for OpenStream, an independent
streaming app that combines Stremio-style source discovery with Infuse-style local and
NAS playback.

Requirements:

- 1920x1080 television canvas with safe margins and clear remote-focus states.
- Quiet, cinematic dark UI with cyan, coral, and green accents.
- A compact navigation bar, not a marketing landing page.
- Show a connected NAS, active add-ons, source health, and a row of available sources.
- Make the selected source unmistakable from ten feet away.
- Use editable frames, text, shapes, and auto-layout throughout.
